THE ENGINE

Built for changes that have a deadline attached.

The first adapters focus on marketplace/listing state, price movement and availability. Every check keeps the evidence needed to know whether an alert was real.

Price movement

Read structured product metadata or selected page text, then record target crossings and before/after price moves.

Restock state

Watch availability metadata or a phrase such as “In stock” and react when the state changes.

Scoped diffs

Track a CSS-selected region, suppress predictable dynamic text, and keep the resulting version history.

Evidence history

Checks are stored with timestamp, HTTP status, latency, captured text, value, and the signal that fired.

Delivery hooks

Send readable Slack or Discord messages, or route structured JSON into your own automation.

Preflight first

Probe the URL before creating a monitor and reject obvious blocked or browser-only targets instead of pretending they work.

FAQ

What early access can and cannot do.

Public HTML, JSON, XML and feed-style URLs that can be fetched without login. We test a URL before accepting a paid pilot.

The current shared service does not execute arbitrary third-party JavaScript in a browser. The preflight flags obvious browser-only or blocked pages; we reject those pilots instead of charging for an unreliable setup.

The $5 pilot pays for a configured and verified signal, not access to a blank checker. We set the rule, test the target, inspect noise, and demonstrate the live monitor before payment.

Every event is saved in the workspace. PricePulse can also post to Slack or Discord webhooks, or send structured JSON to another automation.
