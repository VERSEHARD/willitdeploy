# Third-party UI package

WillItDeploy uses **Tabler Core 1.6.0**, a human-maintained open-source dashboard UI toolkit by codecalm / Tabler contributors.

- Project: https://tabler.io
- Source: https://github.com/tabler/tabler
- Package: @tabler/core 1.6.0
- License: MIT

The application pins the exact version in `templates/index.html` instead of using `latest`, so upstream UI releases cannot unexpectedly change the layout.
